# 斗地主游戏

我对牌类游戏是一窍不通，但是日常生活中有许多朋友都会玩这个游戏，我认为有必要进行学习一下。

所以通过实现这一个斗地主项目在学习游戏规则的同时，也练习一下自己的代码工程能力。

## 项目架构

### 用户模块

使用 `BasePlayer` 基类，然后有两类具体玩家，真人和 AI。

### 游戏核心规则

1. 各个玩家进行叫地主，确定地主和农民
2. 地主先出牌
3. 玩家可以跳过，如果出牌必须和上一位完全相同的牌型，或者使用炸弹和飞机
4. 如果接下来的两个玩家都跳过，则可以出不同的牌型了
